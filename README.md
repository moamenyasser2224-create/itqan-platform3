# منصة إتقان

هيكل React مبدئي للمنصة، فيه:

- صفحات تسجيل دخول/تسجيل معلم/تسجيل طالب
- داشبورد معلم: إحصائيات، إدارة صفوف ودروس، متابعة طلاب
- داشبورد طالب: صفوفه، عرض الدروس (مسجل/لايف)

البيانات حاليًا وهمية (src/data/mockData.js) عشان تقدر تشوف الشكل والتفاعل فورًا.
الخطوة الجاية: ربط البيانات دي بـ Supabase بدل الملف الوهمي، حسب الـ schema
الموجود في ملف الخطة التقنية.

## التشغيل

npm install
npm run dev

هيفتح على http://localhost:5173 — ابدأ من صفحة /login.

## الخطوات الجاية المقترحة

1. ربط src/data/mockData.js بـ Supabase (auth + database) بدل البيانات الوهمية
2. إضافة رفع فيديو حقيقي (Bunny.net) في صفحة إضافة الدرس
3. تكامل Zoom/Agora SDK لصفحة "انضم للحصة"
4. صفحة اشتراك ودفع (Paymob) للمعلم
